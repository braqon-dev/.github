# Contributing to BRAQON

Thanks for wanting to help! Issues and pull requests are welcome in **English or Spanish**.

## Before you start

- Read the [code of conduct](CODE_OF_CONDUCT.md).
- Security problems go through the [security policy](SECURITY.md), never a public issue.
- For anything bigger than a small fix, open an issue first so we can agree on the approach.

## Pull requests

1. Fork the repository and create a branch from the default branch: `fix/...`, `feat/...` or `docs/...`.
2. Keep the change focused. One topic per pull request.
3. Add or update tests when you change behavior, and update the docs when you change usage.
4. Make sure the project's checks pass locally (each repository's README says how).
5. Write commit messages in the [Conventional Commits](https://www.conventionalcommits.org/) style, e.g. `fix: handle empty amount`.
6. Never commit secrets, real customer data or production credentials. Secret scanning push protection is enabled and will block it.
