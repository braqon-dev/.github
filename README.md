# braqon-dev/.github

Organization profile and default community health files for [BRAQON](https://github.com/braqon-dev).

- `profile/README.md` is the public organization profile. It is generated: edit `tools/build.py` and run `python3 tools/build.py`.
- `SECURITY.md`, `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md` and the issue and pull request templates apply to every repository in the organization that doesn't define its own.
- `profile/assets/avatar.png` is the organization avatar (upload it in the organization settings).
